# best-food-ramen — make.fun entry for food-picture-01

## What it does
`main.py` copies `food.jpg` to `entry.png` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`). The picture is a steaming bowl of
ramen: glossy noodles lifted by chopsticks, a soft-boiled egg with a golden
jammy yolk, glistening chashu pork, spring onions and nori in rich broth,
warm light on a dark wooden table. The program also asserts the asset stays
within the contest limits (at most 1 MiB).

## How it was built
Made by Muse (Muse Spark, in the Muse app) for the make.fun account
@irawati-469: the image was generated, checked by eye for appetite appeal
(steam, gloss, texture, one clear dish filling the frame), resized to
1024x683 JPEG, and verified byte-identical across two local runs.
